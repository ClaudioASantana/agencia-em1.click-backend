# Spec: Agency Modal Redesign

## MODIFIED Requirements

#### Component: Modal Hero & Identity

- The store logo MUST half-overlap the hero image and the content area for a modern "floating" look.
- Use a `backdrop-blur-xl` effect on the modal background to maintain depth.

#### Component: Interactive Actions

- Secondary actions (Heart, Share) MUST use a transparent/blur style with Primary Blue accents.
- The WhatsApp action MUST be prominent, using a brand-compliant gradient but following the button geometry of the Premium Design system.

#### Component: Offer Grid in Modal

- Offers displayed inside the modal MUST follow the "Agency Card" pattern:
  - Primary image focal point.
  - Information badge at the bottom using Glassmorphism.

#### Component: Information Blocks

- Contact items (Address, Hours, etc.) MUST be preceded by a unified icon container style (e.g., circular background in `bg-primary/5`).
- Social Media buttons MUST be redesigned for a "Minimalist Brand" look (e.g., icons with subtle text, avoiding full-width solid color blocks if possible).
