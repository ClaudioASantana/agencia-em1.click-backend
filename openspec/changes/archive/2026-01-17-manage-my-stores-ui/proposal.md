# Change: Manage My Stores UI

## Why

Store owners need a centralized, multi-store management dashboard to view, filter, and manage their establishments, replacing the single-store view limitation.

## What Changes

- Add "Gerenciar Minhas Unidades" screen with grid view and filters.
- Add Store Card component with status badges and quick actions (active offers, visits).
- Add "Add New Store" flow entry points.
- Implement filtering by name, location, and status.

## Impact

- Affected specs: `store-management`
- Affected code: `bureau-frontend/src/views/store`, `bureau-frontend/src/components`
