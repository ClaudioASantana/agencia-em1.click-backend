## ADDED Requirements

### Requirement: Admin Layout

The system SHALL provide a dedicated layout for SaaS Administrators.

#### Scenario: Visual Layout

- **WHEN** a SaaS Admin logs in
- **THEN** they see a persistent sidebar with "Dashboard", "Lojistas", "Planos", "Relatórios" links.
- **AND** a top header with search and notifications.

### Requirement: Store Stats

The "Gestão de Lojistas" view SHALL display high-level statistics.

- **Stats**: Total Stores, Active Stores, New Requests.

#### Scenario: Visual Stats

- **WHEN** accessing the Store Owners view
- **THEN** three summary cards are displayed at the top.
