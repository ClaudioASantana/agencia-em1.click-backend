# Create Agency Landing Page

## Summary

Create a modern, institutional landing page for the "Vitrine" ecosystem in the `vitrine-agencia-em1.click` repository. This page will serve as the gateway to the platform, explaining its value, showcasing features, and providing access points (links) to the Public Storefront and the Bureau (Admin Dashboard).

## Motivation

The platform currently consists of a backend, an admin dashboard, and a public storefront, but lacks a central "home" or marketing page that explains what the platform is and guides users (both customers and store owners) to the right place. The user requested a "WordExpress-style" (WordPress-style) page with descriptions and presentations.

## Proposed Solution

Develop a static or lightweight Vue.js website in `vitrine-agencia-em1.click` with the following sections:

1.  **Hero Section**: Catchy title, brief description, and Call-to-Actions (CTAs) for "Browse Stores" and "Partner Login".
2.  **About**: Explanation of the Vitrine Agency concept.
3.  **Features**: Highlights for User (finding offers) and Store Owners (managing publications).
4.  **Links/Portals**: Direct cards/buttons to accessing `vitrine-frontend` (Public) and `bureau-frontend` (Admin).
5.  **Footer**: Contact info and links.
